### This is my first project which is related to Agentic AI
***this project run in python 3.12***
## Step to run this project
** clone the project **
`git clone "link"`
** Go to the project directory **
`cd python-project`
** create and activate the virtual environment**
`python -m venv virtualenv`
**install the required library from requirement.txt**
`pip install -r requirement.txt`
**run the project**
`python main.py`
